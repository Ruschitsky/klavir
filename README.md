# Клавир

Тренажёр слепой печати: проверка уровня, адаптивная тренировка слабых клавиш и сочетаний, уроки, тесты скорости. Работает без интернета.

Приложение для Mac собирается автоматически на GitHub Actions (см. `.github/workflows/build-mac.yml`).

Локальная сборка веб-части: `cd standalone && npm install && node build.mjs`, результат в `standalone/dist`.
